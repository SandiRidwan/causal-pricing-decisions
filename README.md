## Overview

A portfolio-grade **causal inference** project for pricing decisions. It answers
the question most analytics stops short of:

> *"We ran a discount. Did it actually raise **profit** — and should we keep it?"*

The project estimates the causal effect of a targeted category-discount policy
using **four independent methods**, proves them on data with a **known ground
truth**, attaches **confidence intervals**, runs **placebo and sensitivity
tests**, and ends in an explicit **decision tier** with an **annualised $ value**
— not a chart without a conclusion.

| Property | Value |
|---|---:|
| Methods implemented | **6** (DiD · Event study · Synthetic Control · CUPED · Bootstrap CI · Placebo) |
| Real data (Morrisons catalog) | **11,208 products** (bundled as a compact parquet) |
| Controlled panel | **358,656 rows** (11,208 units × 32 weeks) |
| Validated against ground truth | **yes** (effect planted = −51.5% gross profit) |
| Automated tests | **21 passing** |
| Decision output | **tier + justification + $ range** |
| Estimators proven on synthetic data | **DiD recovers planted effect (<3 error)** |

## Why This Project Is Hard

> *"Two A/B tests are easy. Proving an estimator is CORRECT is the real test."*

```
Correlation ("discount weeks had more units")   →  confounded, misleading
Causal estimate (DiD / Synthetic Control)        →  effect NET of trend      ✓
Ground-truth validation (planted effect)         →  proves the estimator     ✓
```

Anyone can compute an average. The hard part is: **(1)** removing the trend that
would have happened anyway, **(2)** proving your method recovers a *known* effect,
**(3)** being honest when the answer is "don't do this", and **(4)** turning the
result into money and a decision.

## 🧠 What Makes This Different

### 1. Estimators validated against GROUND TRUTH

The price panel is generated by a **documented data-generating process** with the
true effect **planted**. We then check the estimators recover it:

```python
# tests/test_causal_validity.py
panel = _clean_did_panel(effect=50.0)      # plant +50
assert abs(did_estimate(...)["did_abs"] - 50.0) < 3.0   # DiD recovers it ✓
```

This is a **Monte-Carlo study** — the standard way econometricians verify a method
— applied in a portfolio project. It is what turns "I ran a regression" into
"I proved my estimator is unbiased on known data".

### 2. Four methods, cross-checked (not one number)

| Method | Purpose | Result on the policy |
|---|---|---|
| **Difference-in-Differences** | effect net of trend | −8.90% gross profit |
| **Event study** | tests parallel-trends assumption | slope ≈ 0, p large → **assumption holds** |
| **Synthetic Control** | counterfactual from donor pool | **−36.08%** |
| **CUPED** | variance reduction (33.7% less) | tighter CI |
| **Placebo / permutation** | could this be chance? | p-value reported honestly |
| **Sensitivity** | is the verdict metric-dependent? | direction checked across 3 metrics |

### 3. The answer is honest — and negative

The policy **lowers gross profit** even though it raises units. The decision
engine returns **HENTIKAN (stop)**, because:

```
units_sold   +0.07%   ← looks like success
revenue      −0.56%   ← already negative
gross_profit −8.90% (DiD) / −36.08% (Synthetic)   ← the metric that matters
ground truth −51.48%  ← what really happened
```

> *"Selling more, profiting less"* is the classic pricing trap. This project
> catches it and says so.

### 4. Decision engine with guardrails — no overclaim

A result is only **LAKUKAN (proceed)** if: effect positive **AND** CI excludes
zero **AND** effect is material **AND** the margin guardrail holds. Otherwise →
**UJI ULANG** or **HENTIKAN**. Every verdict carries an auditable justification.
See [`src/decide.py`](src/decide.py) and [`docs/SPEC.md`](docs/SPEC.md).

### 5. Money, not just percentages

```
annualised gross-profit effect = weekly effect × (52 / weeks observed)
reported as a RANGE [low, high] from the bootstrap CI — never a false point
```

## 🏗️ Architecture

```
 Morrisons catalog (REAL, 11,208 products) ─┐
                                            ├─► ingest.py ─► price panel
 Documented DGP (ground truth known) ───────┘        (controlled)
                                                     │
                                    causal.py ───────┤
              (DiD · EventStudy · SyntheticControl ·  │
               CUPED · BootstrapCI · Placebo ·       │
               Sensitivity)                          │
                                                     ▼
                                      decide.py ─► tier + $ impact
                                                     │
                              run_pipeline.py ─► DuckDB marts + report.json
                                                     │
                        ┌────────────────────────────┼──────────────┐
                        ▼                            ▼              ▼
                 app/dashboard.py          src/spec_audit.py   tests/ (21)
```

| Layer | File | Role |
|---|---|---|
| **Spec** | `src/config.py` | single source of truth: policy, metrics, decision thresholds |
| **Ingest** | `src/ingest.py` | real catalog + documented panel DGP |
| **Causal** | `src/causal.py` | 6 estimators + placebos + sensitivity |
| **Decision** | `src/decide.py` | estimates → action tier + $ (with guardrails) |
| **Orchestration** | `src/run_pipeline.py` | end-to-end, one command |
| **App** | `app/dashboard.py` | Streamlit: DiD · event study · synthetic · robustness |
| **Audit** | `src/spec_audit.py` | verifies every output against the spec |
| **Tests** | `tests/` | data quality · estimator validity · decision spec |

## ⚠️ Honest Boundaries

| Boundary | Detail |
|---|---|
| **Simulated panel** | The weekly price panel is a *controlled simulation* with a known ground truth — **not** observed market prices. Real prices exist only in the cross-sectional catalog. This is deliberate: you cannot prove an estimator without a known truth. |
| **Assumed COGS** | No real cost data → gross margin assumed **30%** (explicit, in `config.py`). |
| **Unobserved confounding** | Real markets have confounders not modelled here. |
| **Educational** | Not investment or commercial-pricing advice. |
